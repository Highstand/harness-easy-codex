# 카드뉴스 기획과 제작

경로는 프로젝트 루트 기준이다. `AGENTS.md`, `brand.md`, `content-design.md`와 지정 원본을 읽고, 있으면 이번 조사 보고서를 참고한다.
연결 도구에 전용 스킬이 있으면 사용 전에 읽는다. 오래된 도구 이름을 고정하지 않는다.

## A. 주제와 기획

주제 추천이면 3개의 주제·핵심 메시지·시각 방향을 제시한다. 아직 선택하지 않은 내용을 제작하지 않는다.
선택 후 필요한 서비스 사실·CTA만 질문하고, 사용자 답변을 반영해 `plans/{slug}/plan.md`와 `content.json`을 작성한다.
slug는 영문 소문자·숫자·하이픈이다. 기존 예제와 다른 이름을 쓴다.

plan.md에는 목적, 대상, 카드별 역할·확정 카피·사진 방향·사진 칸 비율·장식, 원본 대비 변경 이유, 확인할 사실을 표로 정리한다.
경쟁사 근거는 조사 문서에 두고 기획에는 우리 방향과 콘텐츠를 쓴다.

content.json은 카드 배열이다. 아래 예시는 구조 설명용이며 실제 문구와 패턴은 기획에서 정한다.

```json
[{"id":"cover","pattern":"A1 전면 사진 표지","label":null,"title":"확정한 제목","caption":"보충 문장","image":"cover.png","rows":null,"cta":null,"decorations":[]}]
```

`rows`는 [[항목,내용]], `decorations`는 [{asset,x,y,width,height}]다. 제목 줄바꿈은 \n을 쓴다.
한 장에 라벨→핵심 제목→보충 설명의 위계를 유지한다. 번호·시리즈 푸터·새 슬로건을 임의로 추가하지 않는다.
문구와 구성 확인을 받은 뒤 제작한다. 원본 패턴은 참고하되 주제에 따른 변경은 plan.md에 기록한다.

## B. 새 이미지와 필수 프리뷰

기획에 필요한 사진을 연결된 이미지 생성 도구로 새로 만든다. 기획과 맞는 피사체·무드·사진 칸 비율을 사용한다.
새 사진에는 글자·로고·장식을 그리지 않는다. 원본 SVG를 별도 배치한다.
`assets/content/{slug}/images/`와 `image-prompts.json`에 파일·프롬프트·사용 카드·생성 방식을 기록한다.
도구가 없거나 실패하면 사용자에게 필요한 이미지와 프롬프트를 제공한다. 자리 표시 프리뷰를 최종 승인용으로 제시하지 않는다.

```sh
python3 scripts/build-preview.py {slug}
python3 -m http.server 8766 --bind 127.0.0.1
```

프리뷰 주소: `http://localhost:8766/preview/{slug}/index.html`.
포트가 사용 중이면 기존 서버 루트를 확인하거나 다른 포트를 사용한다.
현재 스크립트는 **런메이트 예제용 렌더러**다. 다른 브랜드나 계획한 배치가 다르면 가이드와 기획에 맞춰 수정한다. 지원되지 않는 구성을 임의의 패턴으로 바꾸지 않는다.
`STYLE`만 바꾼다고 모든 좌표·서체 크기·패턴이 바뀌지 않는다. 관련 CSS와 실제 화면까지 확인한다.

브라우저에서 5장을 실제로 열고 원본과 비교한다. 이미지/폰트 로딩, 편집 카피 전체, 제목·본문 강약, 넘침과 겹침, 로고 비율, 사진 크롭을 확인한다.
필요한 수정은 plan.md와 content.json에 함께 반영해 다시 렌더링한다. 의도적 차이·미검증 사항은 `plans/{slug}/source-review.md`에 기록한다.
자동 파일 검사 통과를 시각 검수 통과로 바꾸어 말하지 않는다. 브라우저 도구가 없으면 사용자의 화면 확인을 요청한다.
사용자에게 실제 프리뷰를 보여주고 확인을 받는다. 승인 뒤 카피/사진/배치가 바뀌면 변경된 프리뷰를 다시 확인받는다.

## C. Figma 산출물

사용자가 지정한 결과 파일/페이지에 승인한 프리뷰를 새 섹션으로 제작한다. 원본 링크와 결과 링크를 구분한다.
Figma 읽기만 가능한 도구로는 제작 완료를 주장할 수 없다. 쓰기 가능한 Figma 도구를 확인하고, 없으면 연결을 안내한다.
가이드·원본 에셋·확정 content.json을 사용한다. 로고와 장식은 원본 SVG/노드를 그대로, 사진과 텍스트는 별도 레이어로 배치한다.
전체 카드의 스크린샷으로 대체하지 않는다. 컴포넌트/변수 연결은 기본 요구가 아니다.
`txt-*` 템플릿 전용 이전 JS는 `scripts/legacy/`에 보관되어 있다. 기본 제작에는 사용하지 않는다.

제작 후 노드의 문구와 렌더를 승인 프리뷰와 대조하고 `preview/{slug}/figma-delivery.json`에 실제 fileKey, section, cards[{id,url}], status, 미검증 사항을 기록한다.
일부 실패는 partial, 미실행은 not-started로 남긴다. 기존 예제의 노드 링크를 새 결과로 반환하지 않는다.
마지막에 기획·프리뷰·Figma 링크와 확인하지 못한 항목을 짧게 보고한다.
