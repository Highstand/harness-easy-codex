# 런메이트 카드뉴스 기획 · lonely-evening-run

## 방향
- 주제: 혼자 뛰기 심심한 저녁 — 혼자 달리다 문득 심심해진 날의 마음
- 남기고 싶은 한 문장: 혼자 뛰기 심심한 날, 오늘은 함께 달려볼까요?
- 목표 하나: 공감에서 시작해, 주변 모임을 부담 없이 둘러보게 한다

## 카드 구성
| # | 패턴 | 역할 | 들어갈 내용 한 줄 |
|---|---|---|---|
| 1 | A1 전면 사진 표지 | 공감 진입 | 혼자 뛰는 저녁의 심심함을 꺼낸다 |
| 2 | A2 가로 사진형 | 그 순간을 짚기 | 혼자 뛰는 길이 길게 느껴지는 순간 |
| 3 | A2 전폭 사진형 | 부담 낮추기 | 천천히 달려도 괜찮다 |
| 4 | A2 정보형 | 가볍게 상상하기 | 예시 모임 정보 3행 |
| 5 | A3 행동 마무리 | 다음 행동 | 함께 달려볼까요? → 주변 모임 둘러보기 |

추천안(A1 / A2 / A2 / A2 정보형 / A3) 그대로 유지했다. 이유: 사진 2장 연속(2·3)으로 감정을 쌓은 뒤 정보형 한 장을 두는 편이 "공감 → 안심 → 가벼운 상상 → 행동" 순서가 가장 자연스럽고, 다른 순서는 정보형이 감정 흐름을 끊는다. 2장은 가로 사진형, 3장은 전폭 사진형으로 두 패턴이 겹치지 않는다.
