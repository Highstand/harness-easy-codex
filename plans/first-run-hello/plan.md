# 첫 러닝 모임, 무슨 말을 꺼낼까요?

- slug: first-run-hello
- 목적: 첫 모임의 어색함에 공감하고 작은 인사로 함께 달리기를 상상하게 한다.
- 대상: 러닝 모임의 첫 만남이 부담스러운 입문자와 일상 러너.
- 승인: 사용자가 주제 1번·5장 구성 선택 후 제시한 문구와 구성에 “응 시안으로 보여줘”라고 답함.
- CTA: 가상 서비스 시안용 “주변 모임 둘러보기”. 실제 링크·참여 경로 없음. 클릭 이동하지 않으며 시안 안내는 카드 밖에 둔다.
- 기준: https://www.figma.com/design/1D7Jqr9ku3boaa7GVbeAUm/?node-id=186-3741
- 상태: 사용자 HTML 프리뷰 승인 완료. 지정 섹션 206:292 오른쪽에 Figma 5장 제작 및 렌더 검수 완료. 결과 섹션 209:296.

## 원본 대비 변경 이유

- 원본의 정보형을 가로 사진형으로 바꿔 인사와 대화 장면을 각각 보여준다. 정보 행은 사용하지 않는다.
- 승인한 문구에 라벨이 없어 새 라벨을 추가하지 않는다. 본문 제목 시작은 원본 y262를 유지한다.
- 제목 글자 크기는 표지 88px·본문 80px·CTA 88px, 본문 폭840px 유지. 승인된 긴 보충 문구는 40px을 유지하며 필요하면 2줄로 자연스럽게 감싼다. 사진과 겹치지 않도록 확인한다.
- 표지 큰 별은 긴 제목을 가리지 않도록 생략한다. 전폭 사진형 별은 현재 원본에서 미확인이므로 생략한다.
- CTA 트랙 SVG는 이미 잘린 1080×623 에셋이므로 x0/y720에 원래 비율로 배치한다. 1340×620으로 늘리지 않는다.
- 로고·별·트랙은 확보된 원본 SVG 사용. 번호·시리즈명·푸터·추가 슬로건 없음.

## 사진 방향

| 장 | 장면 | 구도·크롭 |
|---|---|---|
| 1 | 모임에 다가가는 러너의 뒷모습 | 세로 4:5, 하단 30% 노면과 카피 여백 |
| 2 | 손을 가볍게 들어 인사하는 러너 | 가로 839×509, 인물 중앙·우하단 장식 여백 |
| 3 | 출발 전 나란히 서서 대화하는 두 러너 | 가로 839×509, 몸과 표정·우하단 여백 |
| 4 | 같은 방향으로 출발하는 두 러너의 발걸음 | 전폭 1080×896, 상단 그라디언트 여백 |
| 5 | 사진 없음 | 로고·트랙만 사용 |

사진 4개 모두 이번 기획용 AI 신규 생성. 실제 행사·참가 후기처럼 표현하지 않는다. 프롬프트는 assets/content/first-run-hello/image-prompts.json에 기록한다.

## 확인할 사실

시안 범위에 필요한 서비스 사실 추가 없음. 실제 게시·서비스 연결 시 CTA 목적지 확인 필요.
